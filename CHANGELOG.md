# CHANGELOG — BestGames

## [1.0.0] — 2026-10-26
- Создана структура проекта (HTML-страницы, CSS, JS, API, SQL, изображения).
- Верстка 7 страниц: главная, светлая тема, вход, регистрация, профиль, каталог, админ-панель.
- Адаптивная вёрстка: контрольные точки 360 / 768 / 1920 px.
- Тёмная и светлая темы (style.css + light.css).
- Слайдер новинок с индикацией активного слайда и автопрокруткой.
- Быстрый поиск (поле type="search").
- Каталог игр с фильтрацией по жанрам (минимум 6 карточек).
- Личный кабинет: данные профиля, история покупок, смена пароля, выбор темы.
- Админ-панель: добавление игры (название, жанр, разработчик, описание, стоимость, изображение).
- Клиентская валидация форм (e-mail, пароль, телефон, дата рождения, согласие на ПД).
- PHP REST API: регистрация, авторизация, каталог, платёжный вебхук.
- Схема БД MySQL в 3 НФ (users, games, orders, order_items).
- Векторные изображения (SVG): логотип, обложки игр, логотипы партнёров.
- Git-репозиторий с описанием коммитов.
