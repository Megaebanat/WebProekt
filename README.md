# BestGames — интернет-магазин видеоигр

Проект выполнен согласно конкурсному заданию по компетенции «Разработка веб-приложений»
(Региональный этап Чемпионата «Профессионалы» 2026).

## Содержимое проекта
- `index.html` — главная страница (тёмная тема): слайдер новинок, быстрый поиск, преимущества, каталог, партнёры.
- `index_light.html` — главная страница в светлой теме (минимум 4 отличия в дизайне).
- `login.html` — страница входа (e-mail, пароль, кнопка «Войти», восстановление пароля).
- `register.html` — страница регистрации (фамилия, имя, e-mail, дата рождения, телефон, пароль, повтор пароля, согласие на обработку ПД).
- `profile.html` — личный кабинет (данные профиля, история покупок, смена пароля, выбор темы).
- `catalog.html` — каталог игр с фильтрацией по жанрам (360 / 768 / 1920 px).
- `admin.html` — админ-панель (добавление игры: название, жанр, разработчик, описание, стоимость, изображение).
- `css/style.css` — основные стили (тёмная тема, БЭМ).
- `css/light.css` — светлая тема.
- `css/responsive.css` — адаптивность (360/768/1920 px).
- `js/main.js` — слайдер, бургер-меню, тема, профиль, админка.
- `js/catalog.js` — каталог игр и фильтрация.
- `js/auth.js` — клиентская валидация форм входа/регистрации/профиля.
- `api/` — PHP REST API (регистрация, авторизация, каталог, платёжный вебхук).
- `sql/schema.sql` — схема БД MySQL в 3 НФ (users, games, orders, order_items).

## Стек
HTML5, CSS3 (БЭМ, медиазапросы, CSS-переменные через темы), JavaScript (ES6+), PHP (PDO, MySQL), MySQL (3 НФ).

## Требования к окружению
- Веб-сервер с поддержкой PHP 7.4+ и MySQL 5.7/8.0.
- Для запуска API: импортировать `sql/schema.sql`, настроить параметры в `api/config.php`.
- Фронтенд (`*.html`) открывается напрямую в браузере (статические SVG-изображения).

## Перечень профессиональных задач
- Разработка на стороне клиента (HTML/CSS/JS, адаптив, респонсив).
- Разработка веб-приложения на стороне сервера (PHP REST API, MySQL, авторизация/регистрация, вебхуки).
- Разработка информационных ресурсов с использованием готовых решений (SVG-графика, готовые шаблоны верстки).
